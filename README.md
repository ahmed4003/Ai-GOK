# 🎬 AI GOK — Video Enhancer Pro

**محسّن فيديو احترافي يعمل بالكامل داخل المتصفح — بدون رفع أي ملف لأي سيرفر.**

AI GOK هو تطبيق ويب من ملف HTML واحد (Single-File Web App) يتيح للمستخدم تحرير وتحسين مقاطع الفيديو مباشرة داخل المتصفح، باستخدام Canvas 2D وWeb Audio API وMediaRecorder API، دون الحاجة لأي خادم خلفي (backend) أو رفع الفيديو لأي مكان. كل المعالجة تتم محليًا على جهاز المستخدم.

## ✨ المميزات

- **تغيير الدقة (Resolution)**: تصدير الفيديو بدقة 1080p / 2K / 4K / 8K أو الاحتفاظ بالدقة الأصلية، مع حساب الأبعاد فعليًا بناءً على نسبة العرض إلى الارتفاع الحقيقية للفيديو.
- **قص الفيديو (Trimmer)**: أداة تحديد تفاعلية لاختيار بداية ونهاية المقطع المطلوب تصديره فقط.
- **تحسينات حقيقية تُطبَّق على كل إطار**:
  - إعادة أخذ عينات عالية الجودة عند التكبير (High-Quality Resampling)
  - تقليل الضوضاء (Noise Reduction) عبر تمرير Gaussian Blur
  - شحذ ذكي (Smart Sharpening) عبر خوارزمية Unsharp Mask حقيقية
  - تثبيت الاهتزاز (Stabilization – Beta) باستخدام Block Matching لتقدير الحركة
  - تحسين الألوان بأسلوب HDR (منحنى تباين/تشبع، وليس بيانات HDR حقيقية)
  - تصحيح ألوان تلقائي بناءً على تحليل الهيستوجرام الفعلي للفيديو
- **إدارة الصوت**: إزالة الصوت الأصلي بالكامل، أو استبداله بمقطع صوتي آخر يقوم المستخدم برفعه.
- **ضغط وتحكم بالجودة**: أشرطة تمرير للتحكم في التوازن بين الجودة والحجم، ومعدل البت (Bitrate) الفعلي المرسل لمشفّر المتصفح، وسرعة التصدير/التشغيل.
- **صيغ الإخراج**: WebM (VP9/Opus) بشكل موثوق في كل المتصفحات الحديثة، أو MP4 عند دعم المتصفح لذلك (Safari مثلًا) مع رجوع تلقائي إلى WebM عند عدم الدعم.
- **مقارنة قبل/بعد**: أداة Slider لمقارنة إطار حقيقي من الفيديو الأصلي مع إطار من الفيديو المُصدَّر.
- **لقطة شاشة**: حفظ الإطار الحالي كصورة PNG.
- **واجهة مستخدم كاملة**: مشغّل فيديو مخصص، مؤشرات LED لحالة النظام (جاهز / تم التحميل / قيد المعالجة / تحذير / خطأ)، إشعارات Toast، واختصارات لوحة مفاتيح.

## 🛠️ التقنيات المستخدمة

- HTML5 / CSS3 (بدون أي إطار عمل خارجي)
- Canvas 2D API — لرسم ومعالجة كل إطار
- MediaRecorder API — لتسجيل التدفق الناتج كملف فيديو فعلي
- Web Audio API — لمزج ومعالجة المسار الصوتي
- JavaScript خالص (Vanilla JS) بدون أي مكتبات خارجية

## 🚀 طريقة الاستخدام

1. افتح ملف `index.html` مباشرة في أي متصفح حديث (Chrome / Edge / Firefox / Safari).
2. اسحب ملف فيديو أو اضغط لاختياره من جهازك.
3. اضبط الدقة، القص، التحسينات، والضغط حسب الحاجة.
4. اضغط **Enhance Video** لبدء المعالجة الفعلية (المدة تقارب طول المقطع نفسه).
5. حمّل الملف الناتج مباشرة من المتصفح.

> لا حاجة لتثبيت أي شيء أو تشغيل سيرفر — الملف يعمل بشكل مستقل بالكامل (Static/Client-Side فقط).

## ⚠️ ملاحظات مهمة

- لا يوجد أي نموذج ذكاء اصطناعي للـ Super-Resolution يعمل داخل المتصفح؛ التكبير للدقات الأعلى هو Upscaling حقيقي عبر Canvas وليس توليد تفاصيل جديدة.
- "HDR-Style Tone Boost" هو منحنى تباين/تشبع فقط، وليس بيانات HDR حقيقية (لا يمكن للمتصفح إنشاء تدفق HDR فعلي من JavaScript).
- الأداء يعتمد على قوة الجهاز، خصوصًا عند اختيار دقة 4K/8K.
