AI GOK Instructions

How This Actually Works

  • Your video plays in a hidden player while every frame is drawn onto an HTML canvas at your chosen resolution
  • Filters (sharpen, denoise, color, HDR-style tone, stabilization) are applied for real to each frame as it's drawn
  • The canvas is captured as a live video stream and combined with an audio stream (original, replaced, or none)
  • MediaRecorder encodes that combined stream in real time into an actual downloadable file
  • Processing time is roughly equal to your trimmed clip's duration (divided by export speed) — it is not instant because it's genuinely re-rendering every frame

Getting Started

  • Click the upload area or drag and drop a video file to begin
  • Everything happens locally in this browser tab — no upload to any server

Resolution

  • Src — keep the original resolution, just apply filters/compression
  • 1080p / 2K / 4K / 8K — canvas is resized to match, preserving your source's aspect ratio
  • Very large canvases (4K/8K) are heavier to render — expect slower real-time processing and possibly reduced effective frame rate on slower machines

Enhancements

  • High-Quality Resampling — turns on high-quality image smoothing when scaling; turning it off uses nearest-neighbor (blockier) scaling, so you can see the real difference
  • Noise Reduction — a real blur pass that trades a little detail for smoother, less grainy footage
  • Smart Sharpening — a genuine unsharp-mask convolution on each frame; automatically switches to a lighter contrast-based approximation at very high resolutions to keep exporting in real time
  • Stabilization (Beta) — estimates frame-to-frame motion with block matching and smooths it out; works best on small handheld shake, not large camera pans
  • HDR-Style Tone Boost — a real contrast/saturation curve, not actual HDR metadata (browsers can't author real HDR video streams from JS)
  • Auto Color Correction — samples the actual brightness/contrast histogram of your clip and computes real correction values automatically

Audio Tools

  • Remove Audio — the exported file genuinely has no audio track
  • Add / Replace Audio — mixes in a real audio file you choose in place of (or as) the soundtrack

Compression

  • The quality slider and bitrate slider set the real videoBitsPerSecond passed to the browser's encoder
  • Actual resulting file size depends on your footage's real complexity — the after/before comparison you see is measured from the real output file, not simulated
